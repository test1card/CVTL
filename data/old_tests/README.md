# Транскрипция стационарных испытаний KDE420SA, этап I

Источник восьми строк — опубликованная таблица [§2.3 ТЗ](../../TZ.md#23-прошлые-испытания-этап-i). Это машинная транскрипция ТЗ. Исходную фотографию журнала предстоит сверить отдельно.

В ТЗ температурные столбцы уже подписаны по физическим ступеням. Для входного CSV исторические заголовки восстановлены по §2.2. `T1_K` содержит температуру холодной `stage2`, `T2_K` — тёплой `stage1`. Десятичные запятые заменены точками. Токи и напряжения ветвей даны в амперах и вольтах, мощность — в ваттах, температуры — в кельвинах.

Пустые поля токов строки 1 соответствуют неразборчивым записям. Нули напряжений и опубликованной мощности сохранены. В строке 8 число 24,5 К сохранено, а вопросительный знак перенесён в `T2_questioned`. Строка 7 фиксирует инверсию ступеней. Условия опыта — без жидкого азота и без экрана.

[Опорный CSV](../machines/kde420sa_stage1_data.csv) получен из строк 1–6. Колонка `p_net_w` содержит опубликованную подведённую мощность по соглашению §14.3. Паразитные притоки в этих точках не вычтены. Строка 7 доступна из полного импорта для теста инверсии, строка 8 сохраняется вне опорной подгонки.
