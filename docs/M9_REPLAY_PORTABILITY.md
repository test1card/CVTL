# M9. Переносимость реплея A1

Штатный реплей архива M8 `run-01`, записанного на macOS, на Ubuntu доходил до записи 6116, такта 128. Контейнер, контрольные суммы и 14 314 исходных записей читались полностью. Сравнение температуры тела остановило реплей после 125 проверенных тепловых шагов. Из-за этого анализ возвращал «не определяется».

В диагностической копии разница температуры на первой несовпавшей записи составила один шаг `f64`, около `3,55e-15 К`. Наблюдалось различие в `log10(29,75)` при восстановлении кривой `cp(T)` меди OFHC из архивного каталога. По 300 тактам максимумы составили `2,84e-14 К` и `1,11e-15 Вт` для температуры тела и запроса. В отдельной шеститактовой записи обе ОС получили одинаковые знаковые изменения энтальпии около −194, +194 и +78 Дж при энтальпиях 194–466 Дж. Диагностика сохранена в `.local/GRACE-M9-A1-ACCEPTANCE/portability/` и `.local/GRACE-M9-REPLAY-PORTABILITY/dh-diagnostic/`.

## Численная сверка

Для температуры тела, температур на границе изменения параметров, знакового `dH_event` и теплового запроса сравниваются два конечных числа `a`, `b` в единицах СИ.

```text
abs(a − b) ≤ 64 × EPSILON_f64 × max(1, abs(a), abs(b), S)
```

Для температур и мощности `S=1`. Для `dH_event` масштаб `S` равен максимуму модулей пересчитанных энтальпий до и после изменения. Этот масштаб учитывает вычитание двух близких чисел, включая малое `dH_event`. При 30 К граница около `4,26e-13 К`, до 1 Вт около `1,42e-14 Вт`, при масштабе 466 Дж около `6,62e-12 Дж`. Это критерий численного реплея. Физические параметры и уравнения те же.

Удержанное наблюдение `tf` сверяется побитно. После сверки теплового запроса M4/M5 получает записанный вход этого такта. Решения регулятора, исходные команды, ответы прибора и причинное доказательство OFF проходят прежнюю точную проверку. Записанные временные границы, схема и исходные архивы сохраняются.

## Воспроизведение

Скопировать четыре синтетических архива в один каталог `inputs`. Приведены исходные пути в локальной папке свидетельств и SHA-256 `raw.ndjson.zst`.

| Имя копии | Исходный архив | SHA-256 raw |
|---|---|---|
| `recording-v1` | `.local/GRACE-RECORDING-aa1d9f1/nominal-run` | `a8fa93578c893b23e975b0ca05e1bb07bde53ef0fb30957ef2dde28a500ae753` |
| `a1-v1` | `.local/GRACE-A1-REPLAY/nominal-run` | `7c2f756f2a4711faf980c98c2e2fdabbfa12970c545564c31e728133c9d4d5e4` |
| `calibration` | `.local/GRACE-M8-ANALYSIS/calibration-final/run-01` | `aed26995f6776a372ae18798ff4f74433e224affcd806c0116bf5d82ff1f537a` |

```sh
cargo test --locked -p cvtl-cli --lib thermal_roundoff
cargo test --locked -p cvtl-cli --test m7_a1_replay
cargo build --locked -p cvtl-cli
for run in recording-v1 a1-v1 calibration scale; do
    target/debug/cvtl-cli replay "inputs/$run" > "$run-replay.json"
done
target/debug/cvtl-cli analyze inputs/calibration --start 8 --window 12 --seed 20261111 > calibration-analysis.json
```

Повторить на второй ОС с теми же байтами входов. Сверить SHA-256 и список файлов до и после, затем сравнить полный JSON с предыдущими эталонами. Для release использовать `cargo build --release --locked -p cvtl-cli` и `target/release/cvtl-cli`.

## Результат

Проверены macOS 27.2 ARM64 и Ubuntu 22.04.5 LTS ARM64 в локальной VM. Rust 1.94.1 на обеих ОС. Форматирование, сборка, Clippy с `-D warnings`, 268 тестов workspace и запуск с `config/simulator.yaml` прошли. Сеть тестов Ubuntu ограничена `lo`.

| Архив | Совпавшие такты | Записи raw | Кадры | Граница выхода |
|---|---:|---:|---:|---|
| RECORDING v1 | 600 | 28 414 | 226 | `off_verified` |
| A1 v1 | 30 | 1 624 | 12 | `off_verified` |
| M8 `run-01` | 300 | 14 314 | 113 | `off_verified` |
| A1 LOOP со сменой `scale` | 30 | 1 624 | 12 | `off_verified` |

Пять полных JSON-отчётов, включая анализ M8, побайтно совпали с исходными отчётами macOS в debug и release на обеих ОС. Анализ M8 дал `Q2_eff = 3,00021205028674 Вт`, интервал 5–95 % от `2,970029210985283` до `3,029194539606264 Вт`, 4096 выборок и seed `20261111`. Состав и SHA-256 всех 20 исходных файлов совпали до и после каждого запуска. Первый перенос tar на Linux добавил служебные файлы AppleDouble. Проверка состава остановила прогон. Повторный перенос контейнера без расширенных атрибутов прошёл с теми же 20 исходными файлами.

Файловая регрессия сначала остановилась на температуре тела со сдвигом в один ULP. После изменения проверены обе стороны допуска для всех вычисляемых полей. Ненулевой `dH_event` с изменённым знаком и удержанное `tf` со сдвигом в один ULP отклонены. Сдвиг запроса в один ULP прошёл тепловое сравнение и был отклонён на точной проверке исходной записи Control.

Журналы, полный manifest и сводка сверки находятся в `.local/GRACE-M9-REPLAY-PORTABILITY/`. Переносимость подтверждена для четырёх синтетических архивов и указанных сред. Для Ubuntu x86-64 и лабораторного ПК требуется отдельная проверка.
