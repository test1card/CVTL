# M9. Сквозная приёмка A1

Синтетический профиль `test_only` использует эмуляторы Keithley 2604B и Lake Shore 218 на `127.0.0.1`. Реальные параметры головки, аппаратные пределы и измеренные на стенде задержки остаются открытыми. Тепловой шаг и аналитические проверки энергобаланса описаны в [плане A1 HEAD](../.grace/changes/archive/C-CVTL-M7-A1-HEAD/plan.xml). Испытания известной холодопроизводительности приведены в [отчёте M8](M8_ANALYSIS.md).

## Воспроизведение

```sh
cargo test --locked -p cvtl-cli --example m9_a1_acceptance
cargo run --release --locked -p cvtl-cli --example m9_a1_acceptance -- /tmp/cvtl-m9-a1-proof
CVTL_M9_RESTART_EVIDENCE_DIR=/tmp/cvtl-m9-restart-proof \
  cargo test --locked -p cvtl-daemon --test operator_http process_restart_requires_new_arm_and_start
cargo test --workspace --locked
```

Для каждого запуска задать новые каталоги свидетельств. `metrics.json` содержит результат штатной ступени и насыщения, `faults.json` — причины, границы исходных записей и подтверждения выхода. В каталоге каждого сценария остаются снимок, метаданные, raw и, при успешном закрытии, квитанция. `nominal-host.json` и `saturation-host.json` хранят строки планировщика с `scheduled_ns` для сверки с `Inputs` и `Control`. Для перезапуска копируются исходный незакрытый и новый завершённый прогоны.

## Штатный переход и насыщение

Виртуальное тело из OFHC имеет массу 20 кг, начальную температуру 30 К и `scale=0,1`. Пример выполняет 120 тактов с шагом планировщика 100 мс и меняет проводимость с 0,02 до 0,04 Вт/К на такте 50. Тепло в модели головки считается из фактического `U × I` обеих ветвей. Ошибку измеренной мощности считают относительно доступной уставки. Установление измеряется от смены нагрузки до первого отсчёта, после которого весь оставшийся пригодный ряд лежит в полосе 2 %. Модельное время суммируется по исходным тепловым интервалам, время хоста снимается монотонными часами.

| Показатель | macOS ARM64 | Ubuntu 22.04.5 ARM64 | Критерий §8.4 или плана |
|---|---:|---:|---:|
| Ступень запроса | 0,285115 Вт | 0,285115 Вт | 0,20–0,35 Вт |
| Ошибка до / после ступени | 1,743 / 0,303 мВт | 1,762 / 0,310 мВт | max(1 % уставки, 5 мВт) |
| Установление | 600,822 мс | 599,017 мс | ≤ 2000 мс |
| Джиттер, медиана / p95 / p99 / максимум | 0,657 / 1,673 / 1,784 / 1,910 мс | 0,410 / 2,310 / 2,648 / 2,785 мс | p99 ≤ 20 мс |
| Чтение A → последний подтверждённый ответ команды, медиана / p95 / p99 / максимум | 0,742 / 1,016 / 1,057 / 1,257 мс | 1,285 / 2,458 / 2,907 / 3,207 мс | p99 ≤ 300 мс |
| Пропущенные такты | 0 | 0 | Считать явно |
| Хост / модель | 12,037 / 12,001 с | 12,018 / 12,001 с | Измерять раздельно |

При G = 0,60 Вт/К последние 10 из 20 тактов на обеих ОС прошли с ограничением мощности. Последний запрос составил 7,302 Вт на macOS и 7,303 Вт на Ubuntu. Доступная и измеренная мощность составили по 5,455 Вт. Контур оставался в `Running`, модель прошла все 20 шагов. В штатном и ограниченном прогонах подтверждён OFF обеих ветвей и совпал полный реплей до записей 5854 и 1154 соответственно.

## Отказы

В каждом случае перед инъекцией измерен положительный нагрев. Для четырёх отказов приборного тракта по raw отказного такта сверены причина, обе команды OFF, причинный ответ каждой ветви при доступной связи и отсутствие `Drive`. Для отказа writer отдельно проверены отклонённый тик, неизменность принятого префикса и ответы эмулятора. Результаты совпали по типам отказов, реакции и состояниям на обеих ОС.

| Инъекция | Результат на macOS ARM64 |
|---|---|
| `stage2=47 К` при `stage1=44,824 К` | `HeadInversion`, подтверждён OFF. Raw 430 → 431/432 → 436/438 → 439 хранит причину, намерения, ответы и состояние. |
| Однократный корректный RDGST с задержкой 200 мс | `TemperatureStale`, возраст 210,726 мс при пороге 160 мс. На Ubuntu возраст 206,425 мс. Связь и модель пригодны, пропуска тика нет. OFF подтверждён. |
| Разрыв Keithley | `SourceLinkLost`, `Unknown`, запрос резервного отключения. В отказном такте нет пары ответов OFF. После `Recover` подтверждён OFF, затем проверены `Reset`, отклонение `Start` без нового `Arm` и ручной допуск. После нового `Start` измерено 0,393 Вт. |
| Разрыв Lake Shore | `ThermometerLinkLost`, оба OFF подтверждены здоровым Keithley. Снятие инъекции и повторный допуск прошли теми же действиями. После нового `Start` измерено 0,393 Вт. |
| Отказ записи следующего кадра | `Writer(Write)`, `JournalFailure`, `FaultLatched`, закрытие `Failed`. Raw сохранил 627 записей в четырёх кадрах при ранее подтверждённых 627 и принятых на момент отказа 768. Новая команда тика отклонена, счётчик принятых записей сохранился. Обе ветви подтвердили OFF живым обменом, измеренная эмулятором мощность равна нулю. |

Четыре прогона с инверсией, устареванием и разрывами связи закрылись с квитанциями и совпавшим реплеем. У отказавшего writer есть проверенный префикс и отдельное живое свидетельство OFF в `faults.json`. Квитанция в этом случае отсутствует.

Матрица [§10.3 ТЗ](../TZ.md#103-контролируемые-нарушения) использует сквозные прогоны A1 вместе с регрессиями [M5](../crates/cvtl-sim/tests/m5_fault_matrix.rs), [M5 TCP](../crates/cvtl-sim/tests/m5_tcp_supervisor.rs) и [RECORDING](../crates/cvtl-sim/tests/m6_recording.rs). В M5 отдельно проверяются I, U, мощность ветвей и сумма, пропуск тика, очередь прибора, отказ модели, часы, несоответствие каналов, выдержка ошибки мощности и область головки. RECORDING проверяет переполнение raw и доступность OFF при застрявшем writer. Эти случаи используют управляемые входы и часы. Фактические длительности файлового тракта измеряются по запускам и применимы к указанной локальной среде.

## Перезапуск процесса

На macOS тест завершил отдельный демон после подтверждённого ON и измерения 0,392 Вт в исходной записи 326. Старый архив сохранил 336 записей в одном проверенном кадре. Все пять файлов побайтно совпали после повторного запуска. Квитанции нет, знание выхода старого процесса после завершения — `Unknown`.

Новый демон запущен с тем же корнем данных. Старый ID отклонён, незакрытый прогон отсутствует в списке завершённых. У нового прогона есть три нулевых такта до Arm. Start без Arm отклонён, после Arm сохраняется подтверждённый OFF. Порядок raw — отклонённый Start 186, Arm 301, новый Start 340, две команды ON 349/350 и подтверждение 357. Первый штатный такт содержит Inputs 394, Control 396 и положительный Drive 397. В записи 441 измерено 0,392 Вт. Закрытие подтвердило OFF и совпадение реплея с квитанцией до записи 508.

На Ubuntu совпали номера опорных записей и границы 336 и 508. Отдельно сверены пять пар SHA-256 старого архива. Новый прогон после явного Start достиг измеренных 0,392 Вт и завершился с OFF и проверенной квитанцией.

## Свидетельства и границы

Свидетельства хранятся в `.local/GRACE-M9-A1-ACCEPTANCE/`. `macos-final/` содержит release-прогоны macOS ARM64, `t003-restart-macos-final/` — исходные записи перезапуска и сводку с SHA-256. `jammy-final/` содержит release-прогоны, перезапуск и хэши 57 файлов Ubuntu 22.04.5 ARM64. На обеих ОС с Rust 1.94.1 прошли форматирование, сборка, Clippy с `-D warnings`, 265 тестов workspace, два теста метрик примера и запуск с конфигом поставки. Ubuntu проверена в локальной VM, в сетевом пространстве только с `lo`.

В отдельной проверке одного архива M8 текущий реплей Ubuntu остановился на записи 6116 после 125 проверенных тепловых шагов. Первое расхождение пересчитанной температуры тела составило `3,55e-15 К`, один шаг `f64`. Диагностический прогон измерил максимум `2,84e-14 К` по температуре и `1,11e-15 Вт` по запросу. Погрешность связана с реализацией `log10` в расчёте `cp(T)`. Исходные файлы сохранены. Диагностика в `portability/` отделена от штатной приёмки, переносимость требует отдельного исправления и проверки на обеих ОС.
