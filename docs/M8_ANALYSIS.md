# Оценка холодопроизводительности A1

Анализ читает модельные интервалы после сверки операций реплеем. Начало и конец интервала относятся к синтетическому тепловому шагу. Энергия A/B поступает из первичной записи. Для оценки требуются полный совпавший реплей, квитанция завершения и подтверждённый OFF. Разрывы, непригодные отсчёты и слишком короткие записи дают «не определяется» с указанием причины.

## Баланс и условия

Граница включает холодную ступень `stage2` и насадку `tf`. Внутренний поток между ними сокращается при сложении балансов. Знак положительного внешнего притока соответствует теплу, поступившему в эту границу.

```text
Q2_eff = (Σ [E_A + E_B + dt × (G12 × (T1_prev − T2_prev) + Q_wire + Q_other)]
          − C2 × ΔT2 − Cf × ΔTf) / Σdt
```

Член `G12` и приложенный проводник оцениваются на левом конце каждого шага, как в генераторе Эйлера. Проводник забирает тепло со `stage1` и передаёт его `stage2` с той же величиной и противоположным знаком. Используется архивный `k(T)`. Диагностическая проводка M7 и события `dH` виртуального тела относятся к другим расчётам. Средние `stage1`, `stage2`, `tf`, `jacket` в отчёте относятся к выбранному окну синтетического охлаждения.

Производные в середине окна оценивает локальная квадратичная аппроксимация на фактических модельных отметках. Длительность запроса от 10 до 30 с. В баланс входят целые интервалы с предыдущим пригодным отсчётом. Для проверки компенсации насадки вычисляется добавка `Cf × dTf/dt` через существующий режим `FixtureCompensation`.

## Неопределённость и различимость

Для синтетического эталона заданы равномерные полуширины 1 % массы, 1,5 % теплоёмкости, 2 % `G12`, 0,5 % коэффициента энергии и 2 % длины явно приложенного проводника. Полуширины смещения канала и шума отсчёта равны 0,002 и 0,0005 К. Первое приближение складывает коэффициенты всех использований каждого отсчёта и отдельно учитывает смещения. Монте-Карло использует 4096 согласованных реализаций, SplitMix64, seed 20261111 по умолчанию и линейную интерполяцию квантилей. Интервал 5–95 % относится к этим синтетическим допущениям.

Для сопоставимой пары с известной `C2` вводятся `s = ΔTf / Σdt` и баланс `y` до вычитания накопления насадки. Общий отвод и `Cf` следуют из `y = Q2_eff + Cf × s`. Для оценки требуются разность фактических мощностей, различимые наклоны и положительная теплоёмкость. При неизвестном постоянном притоке различима комбинация отвода и этого притока, поэтому отдельный `Q2_eff` не определяется.

## Воспроизведение

```sh
work=$(mktemp -d)
cargo run --release --locked -p cvtl-cli --example m8_a1_calibration -- "$work/calibration"
for run in run-01 run-02 run-03 run-04; do
  cargo run --locked -q -p cvtl-cli -- analyze "$work/calibration/$run" --start 8 --window 12 --seed 20261111
done
cargo run --locked -q -p cvtl-cli -- analyze "$work/calibration/run-01" --pair "$work/calibration/run-03" --start 8 --window 12 --seed 20261111
```

Генератор пишет четыре закрытых прогона по 300 тактов с расписанием 100 мс. Отдельный `truth.json` фиксирует эталон. Значения эталона сравниваются после расчёта. Эмуляторы используют тело из 20 кг OFHC при 30 К и scale 0,1. Пара включает один применённый проводник OFHC сечением 10⁻⁷ м² и длиной 0,20 м. Первый прогон меняет G с 0,02 до 0,04 Вт/К на такте 50. Второй член пары использует G 0,20 Вт/К.

В первой версии генератора отсутствовал отток со `stage1` через проводник. Тест общего баланса воспроизвёл ошибку и подтвердил исправление. Ниже приведены результаты повторных прогонов на исправленном дереве `9533629`.

Повторные отчёты совпали побайтно. SHA-256 исходных файлов совпали до и после анализа. Свидетельства находятся в `.local/GRACE-M8-ANALYSIS/` и `.local/GRACE-M8-ANALYSIS/jammy-final/`.

Экран «Разбор» запрашивает окно 12 с до последней модельной границы и использует тот же seed. Браузерная проверка подтвердила равенство JSON команды `analyze` и экрана на macOS и Ubuntu. Для короткой записи интерфейс показал «не определяется».
