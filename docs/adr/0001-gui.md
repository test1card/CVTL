# ADR 0001. GUI для Фазы A

Статус — принято. Выбор по R-04 подтверждён браузерной проверкой рабочего M7 на Ubuntu 22.04.5 ARM64 и macOS ARM64.

## Контекст

ТЗ §13 требует локальный веб-интерфейс на русском, SVG и графики. В M0 сравниваются Svelte, React, uPlot и ECharts на одном экране с синтетическими данными. Пять рабочих экранов входят в M7.

## Решение

Для M7 выбрать **Svelte 5 + uPlot 1.6** с SVG. У этой пары минимальная сборка в проверенном сценарии. Svelte даёт компактный компонент, uPlot требует небольшой адаптер для обновления данных. React увеличил размер при сопоставимом поведении. ECharts даёт больше встроенных вариантов графиков и настроек. В прототипе использован полный импорт ECharts, который значительно увеличил размер сборки. В M7 проверить доступность, темы, адаптивность, работу с несколькими рядами и длительное обновление графиков. При потребности в возможностях ECharts отдельно оценить модульный импорт.

## Воспроизведение и измерения

Исходники и lock-файл в `ui/`. Требуется Node 22 (см. `.nvmrc`). Команды проверки приведены в [инструкции GUI](../../ui/README.md). Тест поднимает временный сервер на loopback и сохраняет измерения в `ui/results.json`. Он проверяет локальность загрузки, SVG, переключение кнопки и заголовка и изменение изображения графика.

Локальный замер от 10.11.2026 выполнен на macOS ARM64, Node 26.10.0 и Chrome 156.0.8078.81 в headless-режиме. Размер окна 1100×900, в графике 1200 точек, по 30 переключений на вариант. Размер — сумма HTML, JS и CSS после production-сборки, без сжатия. Задержка от программного нажатия до второго `requestAnimationFrame` включает ожидание кадров браузера.

| Стек | Байты | Медиана, мс | p95, мс |
|---|---:|---:|---:|
| Svelte + uPlot | 92 717 | 31,8 | 33,0 |
| Svelte + ECharts | 1 159 694 | 31,8 | 32,8 |
| React + uPlot | 253 474 | 31,6 | 33,0 |
| React + ECharts | 1 322 431 | 31,85 | 33,0 |

Различия времени близки к разрешению метода, поэтому выбор основан на размере сборки. Данные, число точек и порядок переключения одинаковы для всех вариантов. Длительное обновление и масштабирование остаются в программе проверки M7.

В первом запуске Chromium на Ubuntu локаль `en-US@posix` вызывала ошибку `Intl.NumberFormat` при импорте uPlot 1.6.32. Для воспроизводимости теста всем вариантам задаётся `ru-RU`. Поддержку нестандартных локалей в рабочем GUI проверить в M7. [Диагностический запуск CI](https://github.com/test1card/CVTL/actions/runs/42812745553), [параметр locale в Playwright](https://playwright.dev/docs/api/class-browser#browser-new-page-option-locale)

## Рабочий интерфейс M7

Отдельная сборка Svelte и TypeScript размещается в `ui/dist/operator`. Vite задаёт `ru-RU` в одном месте инициализации `Intl.NumberFormat` закреплённой версии uPlot. Браузерный сценарий подставляет `en-US@posix` перед загрузкой модуля и проверяет графики реального демона. Компоновки проверяются при ширине 360 и 1280 CSS px. Команды и снимки собраны в [M7_GUI.md](../M7_GUI.md).
