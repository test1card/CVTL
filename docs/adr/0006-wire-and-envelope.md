# ADR 0006. Проводка и пределы мощности

Статус — принято для расчётов M2. Основание — §5, §6.2 и §7 [ТЗ](../../TZ.md).

## Проводка

`cvtl-physics::wire` решает стационарную задачу для одной жилы на участке постоянного сечения между узлами заданной температуры. Тепловой поток вдоль оси равен `−A·dθ/dx`, где `θ(T) = ∫k(T)dT`. Его производная по длине равна сумме линейной плотности джоулева тепла `I²ρ(T)/A` и, по выбору, излучения. Для излучения задаются температура окружения, эффективная площадь одной жилы и эмиссивность. Модель распределяет эту площадь равномерно по участку. [Константа Стефана — Больцмана, CODATA](https://physics.nist.gov/cgi-bin/cuu/Value?sigma%7Csearch_for=stefan+boltzmann)

Без источников тепла поток находится непосредственно по разности `θ` на концах. С источниками используется баланс потоков на равномерной сетке из 512 интервалов. Нелинейную систему решает метод Ньютона с трёхдиагональным якобианом и уменьшением шага при выходе за область или росте невязки. Критерии решения включают относительный масштаб потока и проверку суммы тепла в оба узла против джоулева и радиационного вклада. Предел итераций, выход из допустимого диапазона и несходимость дают ошибку. Сходимость по сетке для конкретной проводки остаётся отдельной проверкой.

Знак каждого потока положителен, если тепло входит в узел. CLI умножает потоки одной жилы на число одинаковых жил и суммирует их по именам узлов. Фиксированная температура узла представляет измеренный или заданный теплоперехват. Для ненулевого тока нужна таблица удельного сопротивления с указанием источника. Используется кусочно-линейная интерполяция свойств в их диапазонах. Результат в `stage2` можно передать в тепловой баланс из §11.2.

При заданной неопределённости `k` и длины повторяются расчёты для номинала и четырёх сочетаний крайних входов. Масштабирование сохраняет все температурные узлы `k(T)`. Выводится сценарный диапазон. При объединении сегментов складываются нижние и верхние результаты каждого участка. Неопределённость свойств образца, геометрии перехвата, тока и излучения требует отдельных данных.

Медный эталон использует [таблицу Lake Shore](../../data/materials/README.md). Две жилы по 0,12 мм² и 0,30 м дают 48,880933 мВт на холодном конце при 77 → 4,2 К, нулевом токе и отключённом излучении.

## Envelope и подбор нагревателя

`cvtl-envelope` вычисляет две номинальные области непрерывной работы Keithley 2604B. Для каждой области масштабируются пределы тока и напряжения отдельными коэффициентами. При `V_force = I·(R_heater + R_loop)` и `V_sense = I·R_heater` мощность нагревателя равна `I·V_sense`. Из двух допустимых режимов выбирается режим с большей мощностью. Номинальные пары 40 В / 1 А и 6 В / 3 А приняты из ТЗ. Производитель указывает полную мощность при температуре окружающей среды до 30 °C в режиме источника. Фактическое ограничение при другой температуре и работа двух каналов проверяются на стенде. [Tektronix SPEC-2602B Rev. D](https://download.tek.com/document/SPEC-2602BD_Feb2022.pdf)

По диапазону `R_heater(T)` возвращается худшая доступная мощность. Для каждой ветви проверяются концы интервала и, если она внутри интервала, точка смены активного режима `R_heater = (6·k_v/k_i) − R_loop`. В каждом режиме мощность имеет максимум или монотонно изменяется на рассматриваемой части диапазона. Два канала считаются независимо. Оценка с ограничениями строится при заданных пределах обоих нагревателей и общем пределе. При `null` выводится оценка источника и явно указывается, каких пределов не хватает. Это расчёт для подбора. Допуск к включению, паспортная область конкретного прибора и дискретность уставки относятся к следующим этапам.
