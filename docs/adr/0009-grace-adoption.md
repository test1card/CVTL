# ADR 0009. GRACE для разработки CVTL с M6 по M9

Статус — принято для M6–M9. Основание — решение владельца от 10.11.2026 о переходе на GRACE 4.2.1 и проверки G1. Спецификацию и план каждого пакета владелец утверждает отдельно.

## Границы

M5 принят для Фазы A на симуляторах. Защиты, расчёты, протоколы и конфигурации сохраняют действующее поведение. В M6 файловый журнал должен подключаться к существующему `SafetyJournal` и сохранять приоритет отключения. Источники требований — ТЗ, GOAL, PLAN и принятые ADR. `.grace` описывает текущие границы, существующие проверки и согласуемые изменения.

Процессный слой — отдельный коммит. Он включает начальный граф и проверки на базе M5, дополнения к правилам и одну draft-спецификацию RECORDING. M0–M5 сохраняются в истории. Для M6 порядок RECORDING → REPLAY → IMPORT. План каждого пакета строится на фактической базе после явного утверждения спецификации владельцем.

## Инструмент

CLI `@osovv/grace-cli` 4.2.1 из [точного коммита upstream](https://github.com/osovv/grace-marketplace/tree/70f5ec4305bb2cc6ed82dea9470a3b810603874b). Bun 1.3.14 и исходники CLI размещаются вне репозитория. Зависимости из просмотренного `bun.lock` устанавливаются с `--frozen-lockfile --production --ignore-scripts`. Команда `bun /путь/к/grace-cli/src/grace.ts --version` показывает версию CLI. Bun и GRACE не нужны для сборки, запуска или работы CVTL.

## Проверки и ограничения

Приёмка G1 включает `grace lint --path . --assertions current` без `--run-commands`, `grace status --path . --json`, прежние проверки и независимое ревью GPT-6 Astra точного дерева. Структурный lint Rust не проверяет соответствие публичного API описанию. Действующие модули описаны в графе и связаны с существующими тестами. Разметка Rust в G1 отсутствует, поэтому автономная готовность модулей в `grace status` остаётся заблокированной. `cvtl-store` отмечен как зарезервированный, проверка границы workspace не является испытанием файловой записи. Зарезервированный `cvtl-analysis` будет добавлен в граф при работе над анализом в M8.

## Откат

Процессный коммит обратим отдельно. При последующем откате сохраняются история M5, действующие требования и все уже полученные свидетельства.
