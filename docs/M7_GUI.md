# Операторский интерфейс M7

Демон CVTL раздаёт рабочий интерфейс по `127.0.0.1`. В интерфейсе постоянно виден режим «Симуляция». Keithley 2604B и Lake Shore 218 работают на локальных эмуляторах.

## Запуск

Нужны Rust 1.94.1, Node 22 и зависимости из `ui/package-lock.json`. Для офлайн-сборки используется подготовленный npm-кэш.

```sh
cargo build --workspace --locked
npm --prefix ui ci --offline --no-fund --no-audit
npm --prefix ui run build:operator
./target/debug/cvtl-daemon serve --assets ui/dist/operator --runs .local/m7-runs --port 0
```

Откройте адрес, который демон напечатает после привязки порта. `--port 0` выбирает свободный порт. Для проверки YAML используется `cvtl-daemon config/simulator.yaml`.

## Прогон

1. На экране «Сценарий» задайте тело, мост, проводку и насадку. Рассчитайте прогноз и подготовьте прогон. Прогноз охватывает 3 с с шагом 100 мс. В режиме `AdditionalLoad` запрос определяется потоком моста. Расчёты проводки при нулевом токе и теплоёмкости насадки доступны в диагностике сценария.
2. На предпусковом экране дождитесь готовности источника, термометрии, журнала и наблюдения M5. Нажмите «Допустить», затем «Пуск» и подтвердите действие. Сопротивление при выключенном выходе показано по состоянию нагрузки эмулятора. Измерение I/V отображается при пригодных ненулевых отсчётах.
3. На экране «Ход опыта» можно менять массу, `scale` и G постоянного моста. Номер такта и номер записи появляются после приёма журналом фактического изменения. Мощности после ограничений и фактические измерения показаны рядом со знаковым запросом.
4. Нажмите «Стоп». Подтверждение OFF отражает состояние обеих ветвей. Статус «Запись завершена» появляется после квитанции файлового тракта. Сбой сохранения квитанции виден отдельным сообщением. На экране «Разбор» выберите один или два завершённых прогона. Реплей показывает границу сверки и последние 240 тактов. Расчёт `Q2_eff` и неопределённости предусмотрен в M8.

Флаг `--test-faults` добавляет в настройки действие «Учебный отказ». Оно вызывает потерю чтения источника на эмуляторе. При `Unknown` выполните «Восстановить связь». Сброс защёлкнутой аварии доступен после подтверждения OFF и требует отдельного подтверждения. Следующий пуск проходит допуск M5.

## Проверка

```sh
cargo fmt --all -- --check
cargo build --workspace --locked
cargo clippy --workspace --all-targets --locked -- -D warnings
cargo test --workspace --locked
npm --prefix ui run build:operator
npm --prefix ui run test:operator
```

Сценарий Playwright запускает реальный демон. При нестандартном каталоге Cargo задайте `CVTL_DAEMON` абсолютным путём к бинарнику. `CHROMIUM_PATH` выбирает локальный Chromium, а `CVTL_M7_SCREENSHOTS` задаёт каталог для пяти снимков. Проверка сравнивает два реальных прогона, вводит отказ источника, восстанавливает OFF и проверяет обновление графиков за границей 240 точек. Подставляется локаль `en-US@posix`. Страница принимает ресурсы со своего origin.

На macOS ARM64 с Node 22.23.4 и Chrome 156 браузерный тест прошёл за 46,38 с. Живой прогон дошёл до 250 тактов при окне 240 точек. На этом прогоне браузер увидел подтверждённый OFF через 107 мс после нажатия «Стоп». Это замер одного синтетического прогона на данном хосте. Журналы в `.local/GRACE-M7-GUI/`.

На Ubuntu 22.04.5 LTS ARM64 команды запущены от непривилегированного пользователя в пространстве имён с одним `lo`. Проверяемое дерево реализации `64a85cb` передано локальным архивом со сверкой SHA-256. Прошли Rust 1.94.1, Clippy и 243 Rust-теста. В Node 22.23.4 и Chromium 141 тест рабочего GUI прошёл за 29,45 с. В этом прогоне Stop → OFF занял 100 мс. Оба сравниваемых прогона воспроизведены, восстановление и сброс после `Unknown` подтверждены. В сравнительных сборках M0 сохранились предупреждения Vite о размере двух вариантов ECharts. Свидетельства в `.local/GRACE-M7-GUI/jammy-implementation/`. Снимки ниже получены в проверке macOS.
